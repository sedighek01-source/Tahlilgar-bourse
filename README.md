# تحلیلگر بورس — سورس‌کد و راهنمای ساخت

اپلیکیشن آموزشی اندرویدی، فارسی و راست‌به‌چپ، **کاملاً آفلاین** (بدون مجوز اینترنت، بدون سرور و بدون هوش مصنوعی) با قلم **وزیرمتن (Vazirmatn)**.

- شناسه بسته: `ir.tahlilgar.bourse` — نسخه 1.0.0 (versionCode 1)
- حداقل اندروید: 6.0 (API 23) — targetSdk: 34
- حجم APK: حدود ۳۲۰ کیلوبایت

## ساختار پروژه

```
AndroidManifest.xml          مانیفست (فقط دو مجوز؛ بدون INTERNET)
src/ir/tahlilgar/bourse/     کد جاوا: MainActivity (پوسته WebView + پل داده) و ReminderReceiver (یادآوری محلی)
res/                         آیکون‌ها، تم تیره، رشته‌ها
assets/www/index.html        رابط کاربری
assets/www/css/app.css       طراحی (تم تیره، RTL، قلم وزیرمتن)
assets/www/js/               util.js (اعداد فارسی، تقویم شمسی، ذخیره‌سازی) · app.js (آکادمی، آزمون، پیشرفت، کتابخانه، تنظیمات)
                             tools.js (ماشین‌حساب‌ها، شبیه‌ساز، ژورنال) · figures.js (نمودارها و تصاویر آموزشی SVG)
assets/www/fonts/            فایل‌های قلم وزیرمتن + مجوز OFL
assets/www/content/          محتوای آموزشی (JSON): course.json · lessons/s1..s6.json · questions.json · library.json · market.json
build.sh                     اسکریپت ساخت APK با ابزارهای خط فرمان SDK
```

## معماری

- **پوسته نیتیو (Java):** یک `Activity` با `WebView` که فقط از `file:///android_asset/` بارگذاری می‌کند. بارگذاری شبکه با `setBlockNetworkLoads(true)` مسدود است و هر نشانی خارجی رد می‌شود.
- **پل داده (`window.Android`):** خواندن فایل‌های JSON محتوا از assets، ذخیره پیشرفت/نمرات/شبیه‌ساز/ژورنال/تنظیمات در `SharedPreferences` روی خود گوشی، و زمان‌بندی یادآوری.
- **یادآوری روزانه:** `AlarmManager.setAndAllowWhileIdle` + اعلان محلی؛ پس از هر اجرا و پس از روشن شدن گوشی دوباره زمان‌بندی می‌شود.
- **تهیه نسخه پشتیبان:** `allowBackup=false` تا داده‌ها از گوشی خارج نشوند.

> سند نیازمندی‌ها Kotlin/Jetpack Compose و Room را «ترجیح» داده است. در محیط ساخت این نسخه، مخازن Maven گوگل در دسترس نبود؛ بنابراین پوسته با Java و SDK خام و رابط کاربری به‌صورت HTML/CSS/JS محلی داخل WebView پیاده شد. همه الزامات قطعی (آفلاین، RTL، بدون مجوز اینترنت، محتوای داخل APK، ذخیره محلی) رعایت شده است. در صورت نیاز می‌توان پوسته را بدون تغییر محتوا به Kotlin منتقل کرد.

## ساخت APK

پیش‌نیازها: JDK 17 یا بالاتر، و از Android SDK: `platforms/android-23/android.jar`، `aapt2`، `dx` یا `d8`، `zipalign`، `apksigner`.

```bash
./build.sh
# خروجی: build/Tahlilgar-Bourse-v1.0.0.apk
```

متغیرهای اختیاری: `ANDROID_JAR` (مسیر android.jar)، `BUILD_TOOLS`، `KEYSTORE` و `KS_PASS`. اگر keystore وجود نداشته باشد، اسکریپت یک کلید جدید در `keystore/` می‌سازد. **برای انتشار عمومی، کلید اختصاصی خود را بسازید و نگه دارید**؛ به‌روزرسانی‌های بعدی باید با همان کلید امضا شوند.

نسخه ابزارهای استفاده‌شده در این ساخت: OpenJDK 21، aapt2 2.19، dx 1.16، apksigner 0.9 (امضای v1 + v2 + v3).

### نصب روی گوشی
فایل APK را به گوشی منتقل و باز کنید. اگر اندروید اجازه نصب از منابع ناشناس را خواست، برای همان برنامه فایل‌منیجر اجازه دهید.

## افزودن محتوا (بدون تغییر کد)

**درس جدید:** یک شیء به فایل `content/lessons/sN.json` اضافه کنید و شناسه آن را در آرایه `lessons` مرحله مربوط در `course.json` بنویسید:

```json
{ "id": "s2l5", "stage": "s2", "title": "عنوان درس", "difficulty": "متوسط", "minutes": 8,
  "objective": "هدف یادگیری",
  "blocks": [
    {"t": "p", "x": "پاراگراف؛ **متن پررنگ** مجاز است"},
    {"t": "h", "x": "زیرعنوان"},
    {"t": "ul", "x": ["مورد ۱", "مورد ۲"]},
    {"t": "formula", "x": "فرمول", "vars": "تعریف متغیرها"},
    {"t": "ex", "title": "مثال حل‌شده", "x": ["گام ۱", "گام ۲"]},
    {"t": "table", "head": ["ستون ۱", "ستون ۲"], "rows": [["الف", "ب"]]},
    {"t": "fig", "k": "trend", "cap": "زیرنویس تصویر"},
    {"t": "note", "x": "نکته یا هشدار"}
  ],
  "summary": ["نکته کلیدی ۱"],
  "review": {"q": "پرسش مرور", "options": ["الف", "ب", "ج", "د"], "answer": 0, "explain": "توضیح"} }
```

تصاویر آماده (`k`): flow، board، rate، cycle، chain، candle، trend، sr، ma، rsi، drawdown، rr، diversify، option. برای تصویر جدید یک تابع به `Figures` در `figures.js` اضافه کنید.

**سؤال جدید:** به `questions.json` اضافه کنید. سه نوع پشتیبانی می‌شود:
- `"type": "mc"` با `options` و `answer` (اندیس گزینه از صفر)
- `"type": "tf"` با `answer` برابر `true` یا `false`
- `"type": "calc"` با `answer` عددی، `tol` (خطای نسبی مجاز، مثلاً 0.01) و `unit`

هر سؤال باید `stage`، `lesson` (برای پیشنهاد مرور)، `topic`، `difficulty` و `explain` داشته باشد. حدنصاب قبولی در `course.json` (`passThreshold`) قابل تغییر است.

**واژه‌نامه، فرمول، چک‌لیست:** در `library.json`. **داده شبیه‌ساز:** در `market.json` (هر نماد آرایه‌ای از `[باز, بیشینه, کمینه, بسته, حجم]`).

پس از هر تغییر، `./build.sh` را دوباره اجرا کنید.

## مجوزهای اندروید

| مجوز | دلیل |
|---|---|
| `POST_NOTIFICATIONS` | نمایش یادآوری مطالعه روزانه در Android 13 و بالاتر؛ فقط وقتی کاربر یادآوری را روشن می‌کند درخواست می‌شود |
| `RECEIVE_BOOT_COMPLETED` | زمان‌بندی دوباره یادآوری پس از روشن شدن گوشی |
| `INTERNET` | **درخواست نمی‌شود** |

## محتوای نسخه ۱

- ۶ مرحله، ۲۴ درس (هر درس: هدف، سطح، زمان، متن، مثال حل‌شده، تصویر/جدول، خلاصه، پرسش مرور)
- ۴۸ سؤال آزمون (۲۱ چهارگزینه‌ای، ۱۱ درست/نادرست، ۱۶ محاسباتی) + آزمون جامع ۲۴ سؤالی
- ۹ ماشین‌حساب، شبیه‌ساز با ۵ نماد آموزشی فرضی (۱۶۰ روز داده)، ژورنال، ۴۸ واژه، ۱۶ فرمول، ۴ چک‌لیست، نمونه گزارش تحلیلی
- ۱۲ نشان، زنجیره روزهای مطالعه (اختیاری)، علامت‌گذاری درس برای مرور

> محتوای آموزشی بازبینی‌شده در آبان ۱۴۰۵ است. مقادیر وابسته به مقررات (دامنه نوسان، کارمزدها) در مثال‌ها به‌صورت فرضی آمده‌اند. پیش از انتشار عمومی، بازبینی تخصصی محتوا توسط یک کارشناس بازار سرمایه توصیه می‌شود.
